    prompt-cleaner
    
      a tiny Burp Suite for Claude Code
    
    
    
    Getting started
    
    
    Point Claude Code (or any Anthropic SDK) at the proxy. In another shell:
    
    
    $ export ANTHROPIC_BASE_URL=http://127.0.0.1:8080
$ claude
    

    
    What the buttons do
    
    
    
      
    Intercept · pause every request, edit URL/headers/body, then forward or drop.
    
      
    AUP → Opus · auto-retry once with Opus 4.6 when the classifier refuses the request. (One retry only; if Opus also refuses, the refusal is forwarded.)
    
      
    Rules · regex match & replace applied automatically to request or response.
    
      
    Replay · clone any captured request, edit, re-send.
    
      
    Clear · wipe all captures from memory.
    
    
    

    
    List item legend
    
    
    
      
     normal completed
    
      
     refused by AUP classifier
    
      
     AUP fallback retry that succeeded (Opus served it)
    
      
     AUP fallback retry that itself failed (Opus refused / error)
    
      
    ✎ = request body or headers were modified by you or by a rule
    
      
    ↻ = manual replay
    
      
    ⤴ = AUP fallback retry
